Implementation notes

  • Placeholders: Switch 2 hostnames (wds2 / cs2), new member ports and Port-channel numbers are assumed — confirm before build.
  • Multi-chassis requirement: because Switch 1 and Switch 2 are separate (not stacked), each pair must run a multi-chassis LAG (Nexus vPC, Arista MLAG, Catalyst StackWise Virtual, etc.) presenting a single LACP system ID. Without it, the PA will only bundle the member(s) toward one switch; the other stays suspended.
  • Layer 3 on MLAG: the /30 peer IP lives on one logical Port-channel. On vPC/MLAG this typically means an SVI on a dedicated VLAN (with peer-gateway / VARP-style config) rather than a routed port-channel — verify the platform's supported L3-over-MLAG design.
  • PA-1420: create Aggregate Groups ae1/ae2 as Layer3, LACP enabled (active, fast). Move IPs, zones and virtual router from eth1/15 / eth1/16 to ae1 / ae2; set members to type Aggregate Ethernet. Members must match speed/media.
  • Outage: moving the IP from the physical interface to the AE drops each link briefly — schedule a change window.
